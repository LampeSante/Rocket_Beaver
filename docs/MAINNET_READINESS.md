## Code freeze

- [ ] Release commit selected

- [ ] Independent review completed

- [ ] Backup created
- [ ] Access documented
- [ ] RPC providers selected
- [ ] Monitoring active

- [ ] Incident contacts assigned

- [ ] Public descriptions match code

- [ ] Preflight passed

- [ ] Monitoring confirmed
