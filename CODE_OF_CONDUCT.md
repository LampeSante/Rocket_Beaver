# Code of Conduct

## Our standards

Project participation should be respectful, constructive, technically honest, and inclusive.

Positive behaviour includes:

- focusing criticism on code and decisions;
- disclosing uncertainty;
- welcoming questions;
- documenting assumptions;
- protecting sensitive security information;
- giving credit.

Unacceptable behaviour includes:

- harassment;
- threats;
- discrimination;
- doxxing;
- deliberate misinformation;
- publication of secrets;
- irresponsible disclosure of exploitable vulnerabilities.

Maintainers may remove content or restrict participation when necessary to protect contributors or the project.
